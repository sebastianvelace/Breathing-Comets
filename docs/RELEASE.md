# Submission and freeze handoff

The written submission is [SUBMISSION.md](SUBMISSION.md), generated by
`pipelines/submission.py` from the shipped product JSON. The team supplies the
video URL separately and writes the sole prior-work disclosure marker.

The freeze is **2026-11-15 at 21:00 America/Bogota**; submit before 22:00.
Do not describe that future checkpoint as already executed.

At the freeze, record the current `main` commit and rerun:

```sh
git status -sb
git rev-parse HEAD
uv run pytest -q
uv run pytest -q -m network
cd apps/web
npm run check
npx vitest run tests
npm run build
PLAYWRIGHT_BASE_URL=https://breathingcomets.org npx playwright test --trace off
```

Run web check, Vitest and build sequentially: each may regenerate the same
Paraglide files. Playwright needs its matching Chromium installation; this
machine currently uses `PLAYWRIGHT_BROWSERS_PATH=/tmp/breathing-comets-browsers`.

Manually inspect all five prepared targets in production, including Blink,
Diff λ, epoch-aware Gaia and a restored shared URL. Confirm English/Spanish,
the written figures against the JSON and the final public video link. Record
the observed results and remaining failures in `STATUS.md`.

After the final push, verify the exact author/committer identity, zero prohibited
commit-message attribution matches and only the remote `main` branch. Preserve
the user's separate video work.

## Explicit limits to retain

- R Dra D6's retained source coverage ends in June; its September baseline
  acceptance remains failing and must not be presented as passed.
- A fresh arbitrary field can require more than four seconds of acquisition.
  Warm-metadata and response-cache results are distinct measurements.
- JPL background identification can be unavailable; this must not delay images
  or be presented as an empty successful catalog.
- No continuum-subtracted comet gas map is supplied. Unsupported August H₂O
  validation stays withheld; band images must not be relabelled as gas maps.

The API now keeps its existing single machine running to avoid a suspend/start
delay. This uses continuous compute; there are no additional replicas. The
setting can be reversed in `services/api/fly.toml` when appropriate.
